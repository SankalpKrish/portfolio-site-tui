The Procrastination Engine is a clock made of several tiny clocks. It is time within a time
within a time — each layer tracks and renders the one inside it.

I built it in October 2025 for fun, in JavaScript with Canvas. It is the one project here with no
strategic justification whatsoever, and I like it for that.
