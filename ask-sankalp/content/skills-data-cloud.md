I have working experience across all three major clouds — AWS, Microsoft Azure and Google Cloud
Platform — at roughly the same level, which honestly means I have breadth and not much depth in
any one of them.

On the data side I use PostgreSQL, MongoDB and SQL. The SQL is coursework and project work rather
than deep database engineering; I know how to model a schema and write the queries, and I know
what an index is for.

One piece of infrastructure I have actually leaned on hard is Cloudflare. This site is a static
Astro build on Cloudflare Pages, and the `/ask` command behind this answer runs on a Cloudflare
Worker with Vectorize and Workers AI.
