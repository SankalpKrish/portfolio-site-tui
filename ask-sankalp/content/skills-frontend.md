On the frontend I work primarily in React, and more recently React 19 with Next.js 16 using the
App Router. I use TypeScript throughout and Tailwind for styling, with custom CSS-variable design
tokens underneath so the token layer stays separate from the utility layer.

This site — the one you are reading this answer on — is a good example of what I do when I own
the whole thing end to end. It is an Astro site with a WebGPU particle system and a 2D Canvas
fallback, built as a terminal interface.

Design is not a separate skill from frontend for me. On Open Slides and at Open Computer I own
both, including the design systems.
